Импорт теста и Спецификация

Вставьте чистый JSON теста ({...}) или строку Base64. Вы также можете перетащить или загрузить файл .json с устройства.

Вставьте текст или перетащите .json файл:
•
Требования к формату теста:
  • Форматы: чистый JSON (.json) либо строка Base64 (UTF-8).
  • Поля верхнего уровня: id (slug), title (строка), tags (массив), default_timer_minutes (число), questions (массив).
  • Тип choice: содержит options (массив строк) и correct (массив индексов ответа, 0-based).
  • Тип input: содержит correct (массив допустимых строковых ответов). Регистр не имеет значения.
  • Пояснение: поле explanation поддерживает `inline code`.
  • Формулы LaTeX (KaTeX): поля text, options и explanation поддерживают формулы в формате TeX: строчные $...$ и блочные $$...$$. В JSON обратные слэши обязательно экранируются (\\Delta, \\frac{a}{b}).
{
  "id": "linux-test",
  "title": "Основы Linux и формулы",
  "tags": ["linux", "math"],
  "default_timer_minutes": 10,
  "questions": [
    {
      "id": 1,
      "type": "choice",
      "text": "Сигнал для \`kill -9\`:",
      "options": ["SIGTERM", "SIGKILL", "SIGINT"],
      "correct": [1],
      "explanation": "Сигнал 9 — это SIGKILL."
    },
    {
      "id": 2,
      "type": "input",
      "text": "Команда просмотра сокетов:",
      "correct": ["ss", "netstat"],
      "explanation": "ss и netstat используются для вывода сокетов."
    },
    {
      "id": 3,
      "type": "choice",
      "text": "Уравнение баланса активной мощности в энергосистеме:",
      "options": [
        "$P_{ген} = P_{потр} + \\Delta P$",
        "$P_{ген} + P_{потр} = \\Delta P$",
        "$P_{ген} = \\frac{P_{потр}}{\\Delta P}$"
      ],
      "correct": [0],
      "explanation": "Баланс активной мощности: суммарная генерация равна суммарному потреблению плюс потери $\\Delta P$."
    }
  ]
}
