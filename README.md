# Recaller — Самопроверка и активное воспроизведение знаний (Active Recall)

**Recaller** — это легкое, современное и отзывчивое веб-приложение для самопроверки, закрепления и активного воспроизведения знаний (Active Recall). 
Приложение работает одинаково удобно как на **ПК (Windows)**, так и на **Linux**.

---

## ⚡ Ключевые возможности

1. **Дашборд и фильтрация тестов**:
   - Поиск по названию и тегам в реальном времени (`#linux`, `#web`, `#devops`).
   - Отображение лучшего результата прохождения и количества вопросов.
   - Быстрые действия: «Начать», «Редактировать», «Удалить», «Экспорт в Base64».
   - Модальное окно истории прохождений с просмотром прошлых попыток и результатов.

2. **Импорт / Экспорт ключей тестов (Base64 + UTF-8)**:
   - Импорт тестов через закодированную строку Base64 (с полной поддержкой кириллицы UTF-8).
   - Вкладка «Спецификация схемы ключа» с описанием формата, шаблоном и кнопкой копирования в один клик.

3. **Ручной конструктор тестов**:
   - Форма для быстрого создания и редактирования тестов.
   - Поддержка вопросов с вариантами выбора (`choice`, одиночный или множественный выбор) и текстовым вводом (`input`).
   - Пояснения (`explanation`) к ответам с поддержкой форматирования и `inline code`.

4. **Экран прохождения теста (Test Runner)**:
   - Настройка перед стартом: режим таймера (без ограничений / общий таймер / таймер на каждый вопрос) и перемешивание вариантов.
   - Пошаговый режим (по 1 вопросу на экран) с трекером прогресса.
   - Проверка текстового ввода (`input`) нечувствительна к регистру (`case-insensitive`) и лишним пробелам.
   - Поддержка горячих клавиш: `1-9` для выбора вариантов, `Enter` для подтверждения ответа. Защита от случайного пропуска вопросов при удержании `Enter`.

5. **Результаты и «Работа над ошибками»**:
   - Итоговый процент верных ответов, визуальный статус и затраченное время.
   - Детальный разбор каждого вопроса с выделением ошибок и подробными пояснениями.
   - Режим **«Работа над ошибками»** (запуск экспресс-повторения *только* тех вопросов, на которые был дан неверный ответ).

6. **Адаптивный минималистичный дизайн**:
   - Выдержан в строгом монохромном стиле (Clean Minimalism).
   - Поддержка тёмной и светлой темы с сохранением выбора в настройках.

---

## 🛠️ Технологический стек

- **Backend**: Python 3 (FastAPI + Uvicorn) — легкий бэкенд с минимальными зависимостями.
- **Frontend**: Single Page Application (SPA) на чистом Vanilla JS (ES6+), HTML5 и Tailwind CSS (CDN).
- **Хранилище**: Локальные JSON-файлы в директории `data/tests/` (тесты) и `data/history/` (история), с автономным фоллбэком на `LocalStorage`, если запуск идет в статическом режиме.

---

## 🚀 Быстрый запуск одной командой

### Windows
Запустите скрипт **`run.bat`** (двойным кликом или из консоли):
```cmd
run.bat
```

### Linux
Запустите скрипт **`run.sh`**:
```bash
chmod +x run.sh
./run.sh
```

*Скрипт автоматически создаст виртуальное окружение `.venv`, установит зависимости из `requirements.txt`, запустит сервер на порту 8000 и откроет браузер по адресу [http://localhost:8000](http://localhost:8000).*

## 📋 Спецификация схемы ключа (для генерации тестов через ИИ)

Текст ниже можно скопировать и отправлять нейросетям (ChatGPT, Claude, Gemini) для автоматической генерации валидных тестов в формате Recaller:

```markdown
# Спецификация JSON-схемы теста Recaller

Формат обмена: строка Base64 в кодировке UTF-8.
Обязательные поля:
- "id": уникальный идентификатор теста (строка slug или uuid).
- "title": название темы или теста (строка).
- "tags": массив тегов (строки).
- "default_timer_minutes": рекомендуемое время в минутах (число).
- "questions": массив вопросов (минимум 1).

Формат вопросов:
1. Вопрос с вариантами ("type": "choice"):
   - "options": массив строк с вариантами ответов (минимум 2).
   - "correct": массив числовых индексов правильных ответов (например [0] или [0, 2]).
   - "explanation": подробное объяснение (строка, поддерживает `inline code`).

2. Вопрос с текстовым вводом ("type": "input"):
   - "correct": массив допустимых строковых ответов (регистр и пробелы игнорируются).
   - "explanation": подробное пояснение правильного ответа.

Пример JSON-шаблона:
{
  "id": "linux-basics",
  "title": "Основы Linux",
  "tags": ["linux", "cli"],
  "default_timer_minutes": 10,
  "questions": [
    {
      "id": 1,
      "type": "choice",
      "text": "Какой сигнал посылает команда `kill -9 <PID>`?",
      "options": ["SIGTERM", "SIGKILL", "SIGINT"],
      "correct": [1],
      "explanation": "Сигнал 9 — это SIGKILL."
    },
    {
      "id": 2,
      "type": "input",
      "text": "Команда для просмотра сокетов:",
      "correct": ["ss", "netstat"],
      "explanation": "Утилиты ss и netstat используются для вывода сокетов."
    }
  ]
}
```
